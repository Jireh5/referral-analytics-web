## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

This shows the data analytics received from the referral_report.csv in the public folder

reports are generated through a pipeline which could be accessed through this link https://github.com/Jireh5/springer-final-assessment-pipeline/
